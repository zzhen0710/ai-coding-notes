# Codex：实践环境与记录方式

Codex 是本课程的主要实践工具，用于任务定义、上下文组织、项目指令、工作流复用、代码修改和验证。课程不以产品命令作为知识分类中心。

## 默认环境

- Windows 为默认学习环境，使用现有编辑器阅读和维护 Markdown。
- 前期在独立小型目录中完成实验，不要求预先迁移 Linux 或配置模型 API。
- 只有实验涉及 Linux 特定行为或需要接入 Linux 工程时，再使用 Ubuntu。
- Mini Agent 阶段逐步使用自己的程序承载机制实验，Codex 继续辅助讲解、开发与审查。
