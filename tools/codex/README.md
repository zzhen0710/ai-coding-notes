# Codex：实践环境与记录方式

Codex 是本课程的主要实践工具，用于任务定义、上下文组织、项目指令、工作流复用、代码修改和验证。课程不以产品命令作为知识分类中心。

## 默认环境

- Windows 为默认学习环境，使用现有编辑器阅读和维护 Markdown。
- 按任务选择独立小型实验或获授权的真实项目实践，不要求预先迁移 Linux 或配置模型 API。
- 项目操作遵循原项目环境；Linux 相关开发与测试在对应 Linux 环境完成，不为适配学习工具迁移项目。
- 工具机制学到够用，围绕任务定义、上下文、修改审查和验证按需补充；Agent 实现留在 Backlog，有实际需求再恢复。

## 每次实践的环境记录

| 项目 | 记录要求 |
| --- | --- |
| 学习环境选择 | Windows 用于笔记与适合的实验，项目任务记录原项目环境 |
| 客户端与版本 | 实践开始时按实际环境填写 |
| 模型与设置 | 填写可见信息，不猜测不可见参数 |
| 任务目录与允许操作 | 每次明确独立实验或真实项目的授权范围 |
| 运行结果 | 引用对应任务的产物、差异与测试证据，个人掌握单独记录在本地计划 |

这里规定环境记录方式，不代表已安装、配置或测试新的工具能力。具体操作页在实际使用时增加，并写明核对日期与适用客户端。
