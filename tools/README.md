## 产品记录

涉及当前行为时，注明客户端、版本（不可获取则标未知）、核对日期、官方来源，以及对应任务的实际验证范围与证据链接。个人掌握状态保存在本地计划。

区分“官方文档如此说明”“本环境可以使用”“本次任务实际验证通过”。不能由其中一项推定其余两项，也不默认不同客户端行为一致。
