## 单元组织

正文按实际问题组织，不要求机械填满同一模板。重要单元通常包含：

1. 解决的问题、前置知识和适用条件。
2. 核心关系、必要推导与小示例；新术语首次出现说明含义。
3. 实验任务、操作前预测和验收条件。
4. 实际结果、变式与失败分析。
5. 可迁移结论、限制及来源。

开头保留用途、关系和边界的快速复习入口，后文保留恢复理解所需的过程与示例。代码只展示解释需要的部分，完整实验材料链接到 Labs。

## 配套实践

采用“Tiny 实验 → 独立变式 → 故障排查 → 阶段综合任务”的递进方式，见 [Labs 规范](../labs/README.md)。

核心单元至少安排一次实际操作、一次独立变式和一次基于证据的复盘。辅助概念可以合并，不为每个术语单独创建实验。

实验前提供目标、材料和验收条件；个人预测、实际过程和复盘只能依据真实输入填写。系统结果与个人掌握分别验证，不以文章整理完成代替学习完成。
