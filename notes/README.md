## 单元组织

正文按实际问题组织，不要求机械填满同一模板。重要单元通常包含：

1. 解决的问题、前置知识和适用条件。
2. 核心关系、必要推导与小示例；新术语首次出现说明含义。
3. 独立实验或真实项目任务、操作前判断和验收条件。
4. 实际结果、变式与失败分析。
5. 可迁移结论、限制及来源。

开头保留用途、关系和边界的快速复习入口，后文保留恢复理解所需的过程与示例。代码只展示解释需要的部分，独立实验材料链接到 Labs，真实项目的源码与测试链接到原仓库中的对应证据。

## 配套实践

根据问题选择 Tiny 实验、独立变式、故障排查或真实项目任务，见 [Labs 规范](../labs/README.md)。这些是实践方式，不要求每个单元重复走完全部层次。

核心能力通过实际操作和证据复盘验证。真实项目已覆盖的目标直接引用已有证据；只对未覆盖的机制或迁移能力补充小实验、变式或故障任务。辅助概念可以合并。

验收关注任务定义、必要上下文、修改检查、有效测试、关键代码解释和小变式或故障处理。允许使用 AI，但学习者需要作出判断并核验依据，不能仅转述 AI 的结论。

实践前提供目标、材料和验收条件；个人预测、实际过程和复盘只能依据真实输入填写。内容整理、系统产出与个人掌握分别记录，个人状态保存在本地计划，不以文章整理或系统任务完成代替个人验收。
