## 学习与收录原则

- 目录按知识主题归档，学习按前置关系推进；有首篇实质正文时再创建主题目录。
- 重要单元围绕问题、必要讲解、实践、核验与复盘推进；用小变式或故障检查迁移，真实项目任务可替代重复的独立实验。
- 基础概念与工具机制学到够用，遇到实际问题再补充；验收关注任务定义、必要上下文、修改检查、有效测试、关键代码解释和变式或故障处理。
- 独立实验的解释与复盘留在知识笔记，材料和代码放入 Labs，双向链接；真实项目的源码与测试留在原仓库。
- 允许使用 AI；内容整理、系统产出与个人掌握分别记录，系统完成任务不自动证明个人已经理解。个人掌握状态保存在本地计划。
- 同一完整正文只维护一处，其他位置引用；不以术语、链接或文档数量衡量进度。
- 经实际案例支持的可迁移经验再进入 Patterns；暂不创建空范式或模板目录。

## 环境与边界

默认在 Windows 维护笔记并进行适合的实验，Codex 是主要实践工具。课程围绕可迁移的概念组织，产品操作单独维护；真实项目遵循原项目环境，Linux 相关任务在对应 Linux 环境完成。

本仓库聚焦 AI 如何参与软件工程，不收纳完整机器学习课程或产品功能大全。Building Agents、Mini Agent 和复杂 Agent 实现列入 Backlog，有实际需求再评估恢复；不默认创建新仓库。
