## 学习与收录原则

- 目录按知识主题归档，学习按前置关系推进；有首篇实质正文时再创建主题目录。
- 重要单元通过“问题 → 必要讲解 → 预测 → 实验 → 变式 → 核验 → 复盘”推进。
- 配套实验的解释与复盘留在相关知识笔记，材料和代码放入 Labs，双向链接。
- 内容整理、实验验证与个人掌握分别记录；系统完成任务不自动证明个人已经理解。
- 同一完整正文只维护一处，其他位置引用；不以术语、链接或文档数量衡量进度。
- 经实际案例支持的可迁移经验再进入 Patterns；暂不创建空范式或模板目录。

## 环境与边界

默认在 Windows 学习，Codex 是主要实践工具。课程围绕可迁移的概念组织，产品操作单独维护；具体实验需要 Linux 时再使用 Ubuntu。

本仓库聚焦 AI 如何参与软件工程，不收纳完整机器学习课程或产品功能大全。Mini Agent 进入完整应用开发后独立建仓，本仓库保留原理与阶段总结，避免重复维护源码。
